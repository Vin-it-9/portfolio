# Vinit Shinde — Portfolio

Personal portfolio of **Vinit Shinde**, a **Java & JVM developer** focused on reliable backend systems, REST APIs, and practical software projects.

**Live website:** [https://vinitshinde.netlify.app](https://vinitshinde.netlify.app)

## About

This site brings together my projects, technical skills, resume, and writing in one place. It is built with Astro and deployed on Netlify.

## What's inside

- Project showcase with tag filtering and pagination
- Technical skills across Java, the JVM, Spring Boot, Quarkus, Micronaut, REST APIs, databases, and build tools
- Resume viewer and download
- Unified blog feed from external publishing platforms
- Accessible, responsive UI with light/dark themes, high-contrast mode, and reduced-motion support
- SEO essentials: canonical URLs, Open Graph and Twitter metadata, JSON-LD structured data, XML sitemap, robots.txt, and an RSS feed

## Tech stack

- [Astro](https://astro.build/)
- TypeScript
- Tailwind CSS
- SCSS
- MDX content collections
- Netlify

## Development

```bash
npm install
npm run dev
```

The site runs locally at `http://localhost:4321`.

## Build

```bash
npm run build
npm run preview
```

The production build is generated in `dist/`.

## Deployment

The site is deployed on Netlify using `netlify.toml`. The build command is `npm run build` and the publish directory is `dist`.

## SEO and indexing

- Canonical site URL: `https://vinitshinde.netlify.app`
- XML sitemap: `https://vinitshinde.netlify.app/sitemap-index.xml`
- Robots file: `https://vinitshinde.netlify.app/robots.txt`
- RSS feed: `https://vinitshinde.netlify.app/rss.xml`

To help search engines discover the site, submit the sitemap in [Google Search Console](https://search.google.com/search-console) and [Bing Webmaster Tools](https://www.bing.com/webmasters).
