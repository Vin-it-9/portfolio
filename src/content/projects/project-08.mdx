## Project Overview

Banner Generator is a Java application built with Quarkus that provides REST-based functionality for banner generation.

The project uses Quarkus for its application runtime and exposes functionality through REST web services. It is structured as a Maven project and supports both standard JVM packaging and native executable builds.

## Technical Challenges

The project explores building a lightweight REST application with Quarkus while maintaining support for both traditional JVM deployment and native executable packaging.

Quarkus provides a development mode with live coding and a dedicated developer UI, while Maven is used to build and package the application. The project can also be compiled into a native executable using Quarkus's native build support, including container-based native builds when GraalVM is not installed locally.

The REST layer provides the interface through which the banner-generation functionality can be exposed to clients, keeping the application accessible through standard web APIs.
