## Project Overview

Preonus Framework is a build-time Java framework for full-stack applications, designed to move dependency injection, configuration binding, and route registration from runtime to compile time.

Instead of relying on runtime classpath scanning, reflection, or proxy generation, Preonus resolves and generates the required application wiring during compilation. This results in fast, predictable startup times, a smaller runtime footprint, and a framework that is designed with native deployments in mind.

## Technical Challenges

One of the main challenges was designing a Java framework that could perform dependency injection and application wiring at build time while still providing a familiar developer experience.

Preonus addresses this by resolving beans and their dependencies during compilation and generating the required application components ahead of runtime. Route registration and other framework infrastructure can also be generated during the build process, avoiding the need for runtime discovery.

Another important focus was native compatibility. By minimizing reflection and avoiding runtime-generated proxies, Preonus is designed to work smoothly with GraalVM Native Image while maintaining a modular and lightweight runtime.

## Key Highlights

Preonus is built around several core ideas:

- Build-time dependency injection with no runtime bean discovery
- Generated beans and routes created during compilation
- No classpath scanning or reflection-based dependency wiring
- Fast and predictable application startup
- Small runtime footprint
- Spring-style annotations such as `@Service`, `@Repository`, `@Transactional`, and `@Controller`
- Full-stack and microservices-oriented architecture
- REST APIs, backend services, and data-access support
- GraalVM Native Image compatibility
- Modular application design
