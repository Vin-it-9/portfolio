## Project Overview

GitRemind is a desktop reminder application designed for developers and programmers who want to keep track of coding competitions and important events.

The application provides an interactive calendar for managing reminders and supports coding contests from platforms such as LeetCode, CodeChef, Codeforces, and GeeksforGeeks. It combines event reminders with desktop notifications so important contests and deadlines are less likely to be missed.

## Technical Challenges

One of the main challenges was designing a reminder system that could handle both one-time and recurring events while providing useful notifications at the right time.

GitRemind supports daily, weekly, monthly, and yearly recurring reminders. Users can configure reminder details such as the date, time, event type, notification duration, recurrence pattern, and recurrence end conditions. 

For coding contests, the application provides a progressive notification system that can send multiple reminders as an event approaches. Notifications can be triggered when the reminder is created, one day before the contest, one hour before it starts, and again when the contest begins. 

Another focus was integrating the application with the desktop environment. GitRemind can start with the operating system, minimize to the system tray, play notification sounds, and maintain a persistent desktop experience instead of behaving like a traditional browser-only application.

## Key Highlights

The project demonstrates practical desktop application and event-management concepts:

- Electron-based cross-platform desktop application
- Interactive monthly calendar
- Coding contest reminders for LeetCode, CodeChef, Codeforces, and GeeksforGeeks
- Daily, weekly, monthly, and yearly recurring reminders
- Progressive notifications for coding contests
- Custom reminder types for meetings, deadlines, personal events, and contests
- System startup integration
- System tray support
- Configurable notification duration and sound
- Responsive GitHub-inspired dark mode interface
- Tailwind CSS-based UI
