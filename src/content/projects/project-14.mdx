## Project Overview

This is my personal developer portfolio, built to showcase my work, technical skills, projects, and experience as a Java and JVM-focused developer.

The website is built with Astro and uses a component-based architecture to keep pages and reusable UI elements organized and maintainable. The portfolio includes dedicated sections for projects, technical skills, resume, contact, and other professional information.

## Technical Challenges

One of the main goals was to create a portfolio that reflects my development style rather than simply presenting a collection of information.

The site uses Astro's static-first architecture together with reusable components, MDX-based project content, Tailwind CSS, and modern frontend tooling. The project is structured to keep content separate from reusable presentation components, making it easier to add and maintain project pages.

Another focus was performance and usability. The site is designed to provide a fast browsing experience while maintaining responsive layouts across desktop and mobile devices.

The portfolio also includes dedicated project pages so each project can have its own technical overview, challenges, screenshots, and implementation details without overcrowding the main projects page.

## Key Highlights

The portfolio demonstrates:

- Astro-based static site development
- TypeScript and component-based architecture
- MDX-powered project content
- Tailwind CSS styling
- Responsive design for desktop and mobile
- Dedicated project detail pages
- Technical skills and project showcase sections
- Integrated resume and contact pages
- Sitemap and SEO support
- GitHub and LinkedIn integration
- Netlify deployment and production hosting
