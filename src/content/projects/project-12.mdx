## Project Overview

Crypto Price API is a Java backend service built with Quarkus and designed to expose cryptocurrency-related functionality through REST web services.

The project uses Quarkus for the application runtime and Maven for build and packaging. It supports both standard JVM execution and native executable builds, making it useful for exploring lightweight Java backend deployments.

## Technical Challenges

The project focuses on building a lightweight REST service with Quarkus while maintaining support for multiple application packaging models.

Quarkus provides a development mode with live coding and a dedicated Dev UI, while Maven is used to compile and package the application. The service can be packaged as a standard Quarkus application or as an uber-jar for simplified execution.

The project also supports native compilation through Quarkus. A native executable can be built directly or through a container-based build when a local GraalVM installation is not available.

## Key Highlights

The project demonstrates:

- Quarkus-based Java backend development
- REST web service development
- Maven-based build and packaging
- Quarkus development mode with live coding
- Standard JVM application packaging
- Uber-jar packaging
- Native executable generation
- Container-based native builds
- Lightweight REST-oriented backend architecture
